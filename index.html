nostra 회차 데이터

로또 6/45 와 연금복권 720+ 의 회차 결과를 정적 JSON 으로 둔 곳이다. nostra 앱은 동행복권을 직접 부르지 않고 이 파일만 읽는다 — 비공식 API 라 단말이 직접 때리면 IP 차단과 스펙 변경에 그대로 노출되기 때문이다. 스펙이 바뀌어도 수집 쪽만 고치면 되고 앱 재심사가 필요 없다.

파일내용
snapshot.json 로또 400회차 · 연금 200회차 + 알고리즘별 집계
stores.json 1·2등 배출점 — 아직 수집하지 않아 빈 배열이다
조건부 GET 을 지원한다. ETag 를 받아 If-None-Match 로 다시 요청하면 변경이 없을 때 304 가 떨어지므로, 앱은 바뀐 게 없으면 본문을 내려받지 않는다.

수집 경로

동행복권 (비공식 API) — 해외 IP 를 차단한다
↓   로컬 launchd · 주 2회 (로또 토 22:30 · 연금 목 21:30 KST)
↓   git push → 이 레포
↓   GitHub Pages — 정적 JSON
↓   앱 (읽기만)
GitHub Actions 에서 돌리다가 옮겼다. 러너 IP 에서는 동행복권 접속이 TCP 연결 단계에서 타임아웃한다 — 응답을 거부하는 게 아니라 패킷이 버려진다. 같은 코드가 국내 IP 에서는 11초에 완료된다.
로또·연금 번호는 참고용이며 당첨을 보장하지 않는다. 추첨은 매 회 독립이고, 이 레포의 검정 결과는 알고리즘 49종 전부 우연과 구분되지 않는다는 것이다. 동행복권의 상표·서비스와 무관하다.
